<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent → ADM Gateway | MCP tool calls carry environment_id and mcp_id; Agent must not forge health state or bypass enablement |
| ADM Gateway → External MCP | HTTP connection to untrusted external MCP endpoint; secrets (tokens) are injected at this boundary |
| Catalog → Status/Inspect/CLI | CatalogEntry.HeaderRefs values must never flow into any user-facing output |
| Secret resolution boundary | os.ExpandEnv runs exactly once at connect time; resolved values must not leak to error messages or logs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | connectExternalMCP error messages | high | mitigate | Error messages strip resolved endpoint URL; MCPError carries identity not connection details |
| T-03-02 | Information Disclosure | environment_inspect / Snapshot output | high | mitigate | CatalogEntry.HeaderRefs stores template strings (${VAR}), not resolved values; resolved values never stored |
| T-03-03 | Tampering | External MCP returns malicious tool definitions | low | accept | ADM does not execute or trust external tool definitions; they are passed through as metadata only |
| T-03-04 | Denial of Service | Unreachable MCP blocks Gateway | medium | mitigate | Probe timeouts (10s) and per-call connect model; broken MCP returns structured error, Gateway continues serving other tools |
| T-03-05 | Elevation of Privilege | Agent bypasses Environment MCP enablement | low | accept | enabledEndpointInfo checks EnabledMCPIDs before any catalog lookup; existing test proves gating |
| T-03-SC | Tampering | npm/pip/cargo installs | n/a | n/a | No package installs in this phase; Go SDK v1.7.0 already a dependency |
</threat_model>
